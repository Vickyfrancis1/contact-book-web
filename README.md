# contact-book-web

A small Flask web app for storing contacts in an SQLite database.

## Features

- Add contacts through a web form
- Empty fields and duplicate names are rejected
- Contacts are listed alphabetically
- The database table is created automatically on first run

## Run locally

```
pip install -r requirements.txt
python app.py
```

Then open http://127.0.0.1:5000/contacts
